## Description

A personal playground for exploring and developing Python applications.

This repository contains practical projects, experiments and small tools

created while learning and working with Python, automation and DevOps technologies.

The focus is on writing clean, maintainable and practical Python code —

from small scripts and CLI tools to testing, packaging and automation.

Topics include:

- Python Development
- Command-Line Tools
- Automation & DevOps
- Testing with pytest
- Application Packaging
- PyInstaller
- GitHub Actions & CI/CD
- Security & Secure Coding
- AI-assisted Development

> Learn. Build. Experiment. Automate.
